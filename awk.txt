This is where most beginners start getting confused.

But I want you to approach awk differently.

# Think of awk as a tool that reads information in columns.

Imagine you have this file called users.txt:
John 25 London
Sarah 30 Birmingham
David 22 Manchester
James 28 Leeds

Each line contains three columns

Now suppose you only want to display the names:

user@machine$ awk '{print $1}' users.txt
John
Sarah
David
James

What is happening?

Let's break it down:

awk = Start using awk.
{ } = Instructions for awk.
print = Display something.
$1 = First column.
users.txt = The file to read.

Understanding the dollar signs:

Expression    Meaning
$0            Entire line
$1            First column
$2            Second column
$3            Third column
$NF           Last column
NF            Number of columns

For example to return the last columns:
awk '{print $NF}' users.txt


This is the basic structure of awk:
awk 'CONDITION {ACTION}' filename

"If this condition is true, perform this action."
That is the most important thing to understand about awk.






Filtering information is where it becomes interesting
Suppose you only want users older than 25;

awk '$2 > 25 {print $1}' users.txt
